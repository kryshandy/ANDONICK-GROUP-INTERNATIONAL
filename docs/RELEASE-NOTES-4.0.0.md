# ANDONICK 4.0.0 — Livraison production candidate

Cette livraison comprend le thème `andonick` 4.0.0, l’extension `andonick-core` 1.0.0 et le guide propriétaire/no-code.

## Points forts

- UX/UI institutionnelle responsive et bilingue FR/EN ;
- contenus, sections, menus, médias, styles et SEO administrables sans code ;
- projets/preuves et demandes conservés dans l’extension compagnon ;
- formulaires protégés et consentement documenté ;
- navigation clavier, focus, réduction des animations et structure sémantique ;
- scripts de configuration, recette et génération des ZIP.

## Important avant production

La release est une candidate technique. Compléter les mentions légales, configurer domaine/HTTPS, SMTP + SPF/DKIM/DMARC, sauvegardes et 2FA, puis signer la checklist de production.

Consulter `docs/INSTALLATION-DEPLOIEMENT.md`, `docs/PRODUCTION-CHECKLIST.md` et `docs/PLAN-SUITE.md`.
